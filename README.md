# 💰 Python Expense Tracker

A simple command-line Expense Tracker built using Python that helps users record and manage their daily expenses efficiently.

This project was developed to practice Python fundamentals by implementing a real-world application using dictionaries, functions, loops, conditional statements, and file handling.

## 📄 Expense File Format

Expenses are stored in the following format:

```
05/08/2026
Food: Rs. 350
Shopping: Rs. 1200
Travel: Rs. 450

06/08/2026
Medical: Rs. 800
Entertainment: Rs. 300
```

Each date represents a separate expense record.

## ⚠️ Limitations

This project was created as a beginner Python project for learning purposes.

Current limitations include:

- Expenses are stored in a text file instead of a database.
- Duplicate categories for the same date are allowed.
- Date format validation is not implemented.
- Invalid numeric input is not handled.
